
# Task 4 - Responsive Website Using CSS Media Queries

## About the Project
In this task, I created a simple website and made it responsive for mobile screens using CSS Media Queries.

The main goal was to make the website look good on both desktop and mobile devices.

## Technologies Used
- HTML
- CSS
- VS Code
- Microsoft Edge

## Features
- Responsive navigation bar
- Mobile-friendly layout
- Cards adjust according to screen size
- Proper text and button sizing
- Responsive design for smaller screens

## What I Did
1. Created a basic website using HTML.
2. Added styling using CSS.
3. Used Flexbox to arrange the website elements.
4. Added media queries for screens below 768px.
5. Adjusted the navbar and cards for mobile screens.
6. Tested the website using Microsoft Edge Developer Tools.

## What I Learned
While working on this task, I learned how media queries work and how to adjust a website for different screen sizes.

I also got practical experience with responsive layouts and testing websites on mobile view.

## Project Files
- index.html - Contains the website structure.
- style.css - Contains styling and responsive CSS.
